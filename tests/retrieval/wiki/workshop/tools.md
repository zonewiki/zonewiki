# Tools

## Torque values

| Bolt | Nm |
|------|----|
| Stem, faceplate | 5 |
| Seatpost clamp, carbon | 5 |
| Crank bolt | 40 |
| Cassette lockring | 40 |
| Pedals | 35 |
| Disc rotor bolts | 6 |

Always the value printed on the part, when there is one.

## Calibration

The torque wrenches go to calibration every January. The truing stand's
gauge is checked against the reference wheel on the wall.

## Borrowing

Tools don't leave the workshop. The loan set (pump, tyre levers, multitool)
hangs by the door and is signed out in the book.
