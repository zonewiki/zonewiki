Connect an assistant

An AI assistant (any MCP client) can search, read and write this wiki and its tasks{{if .User}} as you, {{.User}}: it sees and changes what you do, no more{{end}}. It connects to {{.URL}}.{{if .Viewer}} You are a viewer: your assistant reads, and changes nothing.{{end}}

Sign in from the assistant

In Claude, ChatGPT or another assistant that takes a remote MCP server (a custom connector), add one with the address above. It opens this wiki in your browser, where you sign in and allow it: there is no token to copy.

Claude Code, in a terminal, then /mcp in it to sign in:

claude mcp add --transport http zone {{.URL}}

An assistant that runs on its maker's servers (Claude's apps, ChatGPT) reaches only a wiki that is on the internet, over https. One on this computer (Claude Code) reaches any wiki this computer does.
