What is kept

The counts are kept for {{.Weeks}} weeks, in the wiki's folder .zone/usage/, outside its history: counts.json holds the numbers on this page and no name, users.json the day each user was last active. Whoever runs the server this wiki is on can read the first to see how much it is used. More in the manual.
