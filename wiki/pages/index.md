# Welcome to your Wiki

Your personal knowledge base — everything stored as plain Markdown files.

## Features

- **Write in Markdown** — all pages are plain `.md` files you can edit in any text editor
- **In-browser editing** — click **Edit** on any page to edit it right here
- **Wikilinks** — link between pages using `[[Page Name]]` syntax
- **Full-text search** — use the search bar to find anything instantly

## Wikilinks

Use `[[Page Name]]` to link to another page. For example: [[Getting Started]]

If the target page doesn't exist yet, the link appears in red — click it to create that page.
Use `[[Page Name|custom label]]` to show a different label: [[Getting Started|learn more]].

## Markdown quick reference

| Element | Syntax |
|---------|--------|
| Heading | `# H1`, `## H2`, `### H3` |
| Bold | `**bold**` |
| Italic | `*italic*` |
| Code | `` `inline` `` or fenced ` ``` ` |
| Link | `[label](url)` |
| Wikilink | `[[Page Name]]` |

## Editing

- Click **Edit** (top right of any page) to open the split-pane editor
- The right pane shows a live preview as you type
- Click **New Page** in the nav to create a new page
